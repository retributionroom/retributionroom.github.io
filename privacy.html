Privacy Policy

Last updated: October 2, 2026

This policy covers the Retribution Room publishing tool ("the app"), a private tool used only by the owner of the Retribution Room YouTube channel.

What the app accesses

With the channel owner's Google sign-in, the app uses the YouTube Data API to upload and schedule the channel's own videos, set their thumbnails, manage the channel's playlists and read the channel's own statistics. It does not access any other account's data.

How data is stored

The sign-in tokens and upload records are stored only on the channel owner's own computer. The app runs no server and keeps no database, and it collects no analytics.

Sharing

The app does not sell, share or transfer data to anyone. The only data it sends goes to Google's YouTube API, to carry out the actions listed above.

Google API Services

The app's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

You can revoke the app's access at any time at myaccount.google.com/permissions.

Contact

Questions: open an issue at github.com/retributionroom/retributionroom.github.io.
